EvidenceBudget teacher app 0.5.9 — development release

Start the app

1. Extract the downloaded folder completely.
2. Install Python 3.10 or newer if Python is not already installed.
3. On Windows, double-click START_WINDOWS.bat.
   On Mac or Linux, open a terminal in this folder and run: python3 app.py
4. Open http://127.0.0.1:8765 if the browser does not open automatically.
5. Keep the terminal window open while using the app.

In GitHub Codespaces, open the repository root and run:
  git pull --ff-only origin main
If the app is already running, click the terminal showing “EvidenceBudget teacher interface” and press Ctrl+C once. Then run:
  python3 app.py --host 0.0.0.0 --no-browser
Open port 8765 from the Ports panel. If the browser preview reports a version mismatch, stop the old server and reopen the forwarded port after starting the updated app.

Use the app

1. Choose New assignment to begin your own plan, or select a sample plan in the sidebar and choose Use a sample plan.
2. Describe the assignment and what students must demonstrate.
3. Edit checkpoints, their evidence links, delivery conditions and time estimates.
4. If you offer an alternative response format, describe it and decide whether it shows the same learning under equivalent criteria.
5. Review the design, enter the teacher name or identifier, and tick the confirmation box.
6. Choose Confirm review & compare plans. The app opens the plan comparison.
7. For a plan record, choose Create a readable PDF blueprint, then choose Save as PDF in the browser print window.

The teacher interface does not offer JSON downloads. Work is not saved automatically; create a PDF record before closing. The PDF records planning assumptions and the teacher’s review. It is not a validated assessment instrument.

The sample plans contain illustrative assumptions and require review for your teaching context. EvidenceBudget does not call a generative AI model or decide which generative AI uses to permit. It does not infer assessment validity, student learning, authorship or accessibility equivalence. The Codespaces preview is for development and review, not permanent hosting.
