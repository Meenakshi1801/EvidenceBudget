EvidenceBudget teacher app 0.4.2 — development release

Start the app

1. Extract the downloaded folder completely.
2. Install Python 3.10 or newer if Python is not already installed.
3. On Windows, double-click START_WINDOWS.bat.
   On Mac or Linux, open a terminal in this folder and run: python3 app.py
4. Open http://127.0.0.1:8765 if the browser does not open automatically.
5. Keep the terminal window open while using the app.

In GitHub Codespaces, open the repository root and run:
  git pull --ff-only origin main
If the app is already running, click the terminal showing “EvidenceBudget teacher interface” and press Ctrl+C once. Then run:
  python3 app.py --host 0.0.0.0 --no-browser
Open port 8765 from the Ports panel. If the browser preview reports a version mismatch, stop the old server and reopen the forwarded port after starting the updated app.

Use the app

1. Load a worked example or choose New assignment.
2. Describe the assignment and the evidence students must demonstrate.
3. Edit checkpoints, their evidence links, delivery conditions and time estimates.
4. If an alternative response/accessibility route is used, describe it and judge whether it elicits the same evidence under equivalent criteria. The software cannot certify equivalence.
5. Review the current design, enter a reviewer name or identifier, and tick the confirmation box.
6. Choose Confirm review. The app proceeds to plan comparison.
7. For a plan record, choose Download readable PDF blueprint, then choose Save as PDF in the browser print window.

The teacher interface does not offer JSON downloads. Version 0.4.2 also improves page breaks in long checkpoint details. Work is not saved automatically; save a PDF record before closing. The PDF records planning assumptions and a teacher review action. It is not a validated assessment instrument.

The worked cases contain illustrative assumptions and require local expert review. EvidenceBudget does not call a GenAI model and does not infer permissions, validity, learning, authorship or accessibility equivalence. The Codespaces preview is for development and review, not permanent hosting.
